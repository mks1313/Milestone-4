# Milestone-4 Repository at Campus 42 Barcelona

Welcome to my **Milestone-4** repository at **Campus 42 Barcelona**! In this milestone, I have worked on the following projects: **Cub3D**, **CPP**, and **NetPractice**. These projects allow me to showcase my skills in **C programming**, **3D graphics**, **object-oriented programming in C++**, and **networking**. 

## Current Projects

### 1. **Cub3D**
**Cub3D** is a project where I create a 3D environment similar to the classic "Wolfenstein 3D". In this project, I implemented a **raycasting engine** to generate 3D graphics using 2D data. I learned how to work with pixel-based graphics, perform **collision detection**, and simulate a basic 3D world. 

This project significantly deepened my understanding of **3D graphics**, **mathematics for graphics**, and **image rendering techniques**. The focus is on optimizing the rendering loop and ensuring smooth graphics for the player.

![Cub3D Badge](https://github.com/ayogun/42-project-badges/blob/main/badges/cub3dm.png)

### 2. **CPP**
**CPP** is a set of exercises focused on improving my **C++ skills**. I have worked on mastering key features of **C++**, such as **object-oriented programming (OOP)**, **inheritance**, **polymorphism**, **templates**, and **memory management**. These exercises help me improve my programming style and apply C++ concepts in real-world scenarios.

Through this project, I learned how to effectively use C++ to build efficient, scalable software, as well as enhancing my skills with **containers**, **iterators**, and **STL**.

![CPP Badge](https://github.com/ayogun/42-project-badges/blob/main/badges/cppm.png)

### 3. **NetPractice**
**NetPractice** is a project that focuses on networking protocols, communication, and socket programming. I have learned how to create applications that communicate over a network using **TCP/IP** and **UDP**. In this project, I have implemented various tasks such as a **HTTP server**, **client-server applications**, and **network debugging**.

This project significantly improved my knowledge of **networking**, **sockets**, and how to manage communication between distributed systems. It also deepened my understanding of **OSI model layers**, **packet analysis**, and **network security**.

![NetPractice Badge](https://github.com/ayogun/42-project-badges/blob/main/badges/netpracticem.png)
