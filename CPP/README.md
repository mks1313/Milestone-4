# CPP - 42 Project

## Description

**CPP** is a project designed to improve my skills in **C++**, focusing on **object-oriented programming (OOP)**, advanced C++ features, and efficient memory management. This project involves a series of exercises that help me master key concepts such as **inheritance**, **polymorphism**, **templates**, and working with the **Standard Template Library (STL)**.

The primary objective is to enhance my understanding of **C++ fundamentals**, implement solutions using OOP principles, and improve my code efficiency through the use of advanced C++ features.

### Features:
- **Object-Oriented Programming (OOP)**: Implementing classes, inheritance, and polymorphism in C++.
- **Memory Management**: Using pointers, constructors, destructors, and manual memory management.
- **Templates**: Working with function and class templates to create generic code.
- **STL (Standard Template Library)**: Using STL containers like vectors, lists, and maps to store and manipulate data.

## Installation

### Prerequisites

To build and run this project, you need:
- **C++ Compiler**: I used `g++` for compiling the code.
- **Make**: Used to automate the build process.

### Installation Steps

1. **Clone the repository**:

    ```bash
    git clone https://github.com/your_username/CPP.git
    ```

2. **Navigate to the `CPP` directory**:

    ```bash
    cd CPP
    ```

3. **Compile the project**:

    ```bash
    g++ -o cpp_project main.cpp
    ```

4. **Run the project**:

    ```bash
    ./cpp_project
    ```

## Usage

Once the project is compiled, you can execute it and interact with the various exercises included in the project.

- **Exercise 1**: Understanding basic OOP principles.
- **Exercise 2**: Implementing inheritance and polymorphism.
- **Exercise 3**: Working with templates and STL containers.
